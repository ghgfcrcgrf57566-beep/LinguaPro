# LinguaPro interactive audio assets

These short UI sound effects are bundled locally for offline playback in Flutter.

| File | Suggested use |
|---|---|
| button.wav | Tap / select answer |
| error.wav | Incorrect answer feedback |
| movement.wav | Question transition / lesson start |
| success.wav | Correct answer / lesson completion |
| toggle.wav | Toggle / settings interaction |
