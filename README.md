# LinguaPro

منصة تعليم اللغة الإنجليزية من المستوى المبتدئ إلى المتقدم، مع مسار متخصص للإنجليزية القانونية.

## النسخة الأولية

- واجهة عربية/إنجليزية متجاوبة.
- دروس مفردات وقواعد ومحادثات.
- اختبارات قصيرة وتتبع تقدم محلي.
- قسم للإنجليزية القانونية.

## التشغيل

افتح `index.html` في المتصفح. لا تحتاج النسخة الأولية إلى تثبيت حزم.

## ملاحظات

هذه نسخة واجهة أولية؛ ميزات الحسابات والمزامنة والمساعد الذكي تحتاج لاحقًا إلى إعداد خدمات خلفية ومفاتيح API آمنة.
