# LinguaPro — English Learning Academy

مشروع تعليم اللغة الإنجليزية من المستوى المبتدئ إلى المتقدم، مع مسار متخصص في الإنجليزية القانونية.

## محتويات المستودع

- `index.html`, `style.css`, `app.js`: نموذج ويب أولي موجود في جذر المستودع.
- `app/`: مصدر تطبيق Flutter/Dart المخصص لتطبيق Android.
- `.github/workflows/flutter-ci.yml`: سير عمل لفحص Flutter وتشغيل الاختبارات ومحاولة بناء Android App Bundle.

## البنية السحابية المطلوبة

- **GitHub** لإدارة الكود وملفات المحتوى وسجل الإصدارات.
- **HTTPS API** لتقديم المحتوى المنشور إلى التطبيق.
- **قاعدة بيانات سحابية** لحسابات المستخدمين والتقدم والمفضلة والمحادثات.
- **خادم خلفي** للاتصال الآمن بخدمات الذكاء الاصطناعي.

GitHub ليس قاعدة بيانات تشغيلية للمستخدمين. لا تضع رموز GitHub أو مفاتيح الذكاء الاصطناعي أو بيانات قاعدة البيانات السرية داخل تطبيق الهاتف.

## تشغيل تطبيق Flutter

راجع `app/README.md`. يلزم تثبيت Flutter SDK وأدوات Android محليًا. لا تزال خدمات API وقاعدة البيانات والذكاء الاصطناعي بحاجة إلى إعداد ونشر مستقلين؛ لا يُدّعى أنها متصلة في النسخة الحالية.

## حالة المرحلة

المرحلة الأولى تضيف هيكل Flutter والواجهة الرئيسية العربية وطبقة API أولية واختبار واجهة وسير عمل CI. لم يُنفّذ بناء Flutter فعلي في بيئة هذه المحادثة؛ ستجري محاولة التحليل والاختبارات وبناء AAB عند تشغيل GitHub Actions.
